# Student Academic Performance Prediction with AI

An introductory data analytics and predictive machine learning project completed for the IBM SkillsBuild Data Analytics with AI Academic Internship Program in association with BharatCares and AICTE.

## Project Overview
This project examines student performance metrics to identify key drivers of academic success and deploys a Multiple Linear Regression AI model to predict final exam performance.

## Technologies Used
- Python 3.x
- NumPy & Pandas: Data manipulation and structure checks
- Matplotlib & Seaborn: Data visualization and correlation mapping
- Scikit-Learn: AI modeling and regression metrics

## Dataset
- Source: [Kaggle Student Performance Dataset]
- Key Features: Study hours, attendance rate, previous test score, sleep hours, and final grade.

## How to Run
1. Clone or download this repository.
2. Install the required Python packages:
   
   pip install -r requirements.txt
